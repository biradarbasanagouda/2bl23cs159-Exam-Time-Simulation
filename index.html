Simple Exam Timer Simulator

This application demonstrates the use of HttpSession in Java Servlets. Click the button below to start an exam. The servlet will store the start time in your session and show the elapsed time in MM:SS format on every refresh.

  • Click Start Exam to begin the timer.
  • Click Refresh on the next page to update the elapsed time.
  • Click End Exam to stop the session and view your total time.
  • If 60 minutes pass, an "Exam time over!" message is shown.
